# Ontology

This file maps symbolic language to candidate mathematical interpretations.

## completion

Possible interpretations:

- `digital_root_b(n) = b - 1`
- `n ≡ 0 mod (b - 1)`
- terminal state of an iterated digit map
- fixed point of a transformation
- maximal state in a finite residue cycle

## mirror

Possible interpretations:

- palindrome
- digit reversal
- involution
- symmetry under a group action
- automorphism
- reflection in a graph or geometric object

## gate

Possible interpretations:

- divisibility predicate
- residue class restriction
- transition condition in a finite automaton
- threshold event in a dynamical system

## resistance

Possible interpretations:

- primality
- low factor count
- large smallest prime factor
- long orbit under an iterated map
- invariant under transformation
- avoidance of collapse into a small state

## collapse

Possible interpretations:

- digit-sum iteration
- digital root
- factorization into primes
- convergence to a fixed point
- many-to-one map
- entropy reduction

## vibration / resonance

Possible interpretations:

- Fourier feature
- residue frequency
- residue shadow of an offset pattern
- local survival factor
- truncated singular-series factor
- spectral graph value
- periodic orbit
- autocorrelation in a sequence

## shadow

Possible interpretations:

- residue shadow `{h mod p : h in H}`
- occupied residue classes
- local obstruction profile
- complement of admissible residue space

## survival

Possible interpretations:

- admissibility of an offset pattern
- positive gate deficit for every checked prime
- avoidance of total residue coverage
- nonzero local survival factor
- finite-wheel residue with all offsets coprime to the wheel
- element of `R_W(H)`

## wheel

Possible interpretations:

- product of small primes
- finite sieve modulus
- residue system for prime candidates
- exact finite distribution space

## root

Possible interpretations:

- digital root
- residue representative
- fixed point of iteration
- algebraic root
- root node of a factorization tree
